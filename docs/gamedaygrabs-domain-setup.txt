GameDayGrabs Custom Domain Setup

This is for the standalone poke-restock-radar Vercel project only.

Do not add gamedaygrabs.com or www.gamedaygrabs.com to Harbor Command.

Vercel Project
1. Open the Vercel project named poke-restock-radar.
2. Go to Settings -> Domains.
3. Add gamedaygrabs.com.
4. Add www.gamedaygrabs.com.
5. Follow the exact DNS records Vercel shows.

The apex domain usually uses an A record to the Vercel value shown. The www domain usually uses a CNAME to the Vercel target shown. Use the exact values shown in Vercel.

Expected Routing
- https://gamedaygrabs.com serves the public GameDayGrabs storefront at /.
- https://www.gamedaygrabs.com serves the public GameDayGrabs storefront at /.
- https://poke-restock-radar.vercel.app continues to serve the private Poke Radar app.
- Public routes include /shop, /product/[slug], /shop/product/[slug], /cart, /shop/cart, /policies, and /contact.
- Private routes such as /app, /dashboard, and /admin still require login before showing private inventory, scanner, market, supplier, receipt, or tracker data.

Domain Readiness Checklist
- Add gamedaygrabs.com to Vercel Settings -> Domains for the poke-restock-radar project.
- Add www.gamedaygrabs.com to Vercel Settings -> Domains for the same project.
- Do not add either domain to Harbor Command.
- Copy the exact DNS records Vercel shows into the domain registrar.
- Wait for Vercel to show Domain configured, Connected, and SSL active.
- Confirm https://gamedaygrabs.com loads the public storefront homepage.
- Confirm https://www.gamedaygrabs.com loads the same public storefront.
- Confirm /contact, /policies, /cart, and product pages work on the public domain.
- Confirm /admin, /dashboard, and /app remain private and require login.

Public Contact
- Public storefront contact email: gamedaygrabs@outlook.com.
- This public business email is shown on /contact, /policies, the storefront footer, and invoice request confirmations.
- This does not change the private admin login email.
- If SMTP is not configured, contact form messages are stored as storefront inquiries in Admin.
- If SMTP is configured later, contact form messages are sent to gamedaygrabs@outlook.com.

Transactional Email Deliverability
- Keep the Resend sending domain verified for gamedaygrabs.com.
- EMAIL_FROM should stay on the verified domain, for example GameDayGrabs Orders <orders@gamedaygrabs.com>.
- EMAIL_REPLY_TO should point to the monitored support inbox, for example gamedaygrabs@outlook.com.
- The app does not check DNS records directly. Confirm SPF, DKIM, and DMARC in the domain DNS and Resend dashboard.
- Add a DMARC TXT record for gamedaygrabs.com if one is not already present.
- A safe monitoring-first starting point is:
  _dmarc.gamedaygrabs.com TXT "v=DMARC1; p=none; rua=mailto:gamedaygrabs@outlook.com"
- After monitoring mail flow, the owner can tighten DMARC later if comfortable.

Public Data Safety
The public storefront must never expose cost basis, supplier/source, market value, profit, tracker data, UPC scanner history, receipts, or admin notes.
